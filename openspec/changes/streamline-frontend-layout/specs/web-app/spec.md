# Spec Delta

## MODIFIED Requirements

### Requirement: 页面集

站点 MUST 采用无侧边栏的顶栏（Header）集约化布局架构；主核心页面为总览 Dashboard、资源库与平台详情页；新平台发现、变更记录与监控状态功能 MUST 在顶栏提供操作按钮并通过模态对话框（Dialog）呈现，且支持通过对应路由直接触发弹窗；主页总览 Dashboard 仅保留核心指标与图表可视化，并提供唯一的资源库主跳转按钮。

#### Scenario: 访问全部核心页面
- **WHEN** 用户导航到任意核心页面或通过顶栏打开辅助功能弹窗
- **THEN** 页面或弹窗正常渲染，且各功能入口可用，不出现资源加载失败

#### Scenario: 顶栏呼出辅助功能弹窗
- **WHEN** 用户在顶栏点击新平台发现、变更记录或监控状态按钮
- **THEN** 系统弹出对应的模态对话框（Dialog）呈现完整数据，不离开当前主页面

#### Scenario: 总览页导航至资源库
- **WHEN** 用户在总览页点击“进入资源库”主行动按钮
- **THEN** 页面平滑跳转至资源库沉浸式刷卡页面

#### Scenario: 平台详情独立展示
- **WHEN** 用户在卡组中点击平台名称或详情链接
- **THEN** 平台独立详情页正常渲染平台信息、各独立权益与证据来源

### Requirement: 视图切换

资源库页面 MUST 专注于单一沉浸式“王权刷卡”（Reign Swipe Deck）核心视图，移除传统的网格卡片与表格列表切换控件；卡组支持左滑忽略、右滑收藏、上滑查看详情、底部快捷按钮与音效反馈；左滑 Pass 操作 MUST 将活动标记为 `ignored` 并持久化到云端数据库；卡组默认过滤掉已收藏及已 Pass 的活动，仅展示未处理卡牌；顶部筛选组 MUST 提供处理状态过滤选项（未处理 / 已收藏 / 已跳过 / 全部）。

#### Scenario: 视图切换保留状态
- **WHEN** 用户在资源库调整筛选或排序并与刷卡卡组交互
- **THEN** 筛选与状态即时同步并在卡牌切换与刷新后保持一致

#### Scenario: 专注刷卡卡组交互
- **WHEN** 用户访问资源库页面
- **THEN** 页面默认且仅以王权卡牌堆叠形式呈现活动卡片，不展示网格或表格视图切换控件

#### Scenario: 默认排除已处理卡牌
- **WHEN** 某活动已被用户收藏或标记为已跳过（Pass / Ignored）
- **THEN** 资源库默认卡组中自动排除该活动，实现收件箱归零

#### Scenario: 筛选已收藏或已跳过卡牌
- **WHEN** 用户在顶部筛选组件中切换到“已收藏”或“已跳过”
- **THEN** 卡组即时呈现对应状态的历史活动，支持撤回或重新查看

#### Scenario: Pass 动作实时云端持久化
- **WHEN** 用户对卡牌执行左滑或点击 Pass 按钮
- **THEN** 系统将该活动在云端持久化标记为 `ignored`，刷新页面后依然生效
