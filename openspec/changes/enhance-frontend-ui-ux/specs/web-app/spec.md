# Spec Delta: web-app

## MODIFIED Requirements

### Requirement: 视图切换

资源库必须（MUST）支持卡片视图与紧凑列表表格视图切换，切换不丢失当前筛选与排序状态；表格视图中必须（MUST）支持按活动选择、表头全选，并提供批量收藏与批量标记已领取的工具栏。

#### Scenario: 视图切换保留状态

- **WHEN** 用户切换视图
- **THEN** 筛选与排序结果保持不变，仅呈现方式变化

#### Scenario: 表格视图批量操作

- **WHEN** 用户在表格视图中勾选一项或多项活动
- **THEN** 页面展示批量操作栏，支持批量加入收藏或批量标记为已领取

### Requirement: 移动端适配

站点必须（MUST）在 iPhone Safari 等移动浏览器可正常使用：导航可达、筛选易操作、资源卡片合理压缩、详情内容无横向溢出；表格视图在窄屏（< 768px）下自适应排版或保证触摸滚动体验良好；移动端搜索、筛选、阅读详情与打开外部领取链接均可用。

#### Scenario: 移动端无横向溢出

- **WHEN** 在移动视口打开资源库与详情页
- **THEN** 页面不出现破损横向溢出

#### Scenario: 移动端弹窗与抽屉自适应

- **WHEN** 移动设备用户点击查看详情
- **THEN** 详情弹窗以全屏或自适应抽屉形式呈现，各项参数与证据链可顺畅触控查阅

## ADDED Requirements

### Requirement: 场景化快捷预设

资源库必须（MUST）提供场景化快捷预设筛选胶囊（如：新手无门槛、开发者 Coding API、1M 超长文本、即将截止捡漏），用户单次点击即可激活对应的组合过滤条件。

#### Scenario: 点击快捷预设应用组合筛选

- **WHEN** 用户点击“新手无门槛”预设
- **THEN** 系统自动过滤出无需绑卡、一次性或针对新用户的活动，并更新当前 URL 参数

#### Scenario: 取消或重置预设

- **WHEN** 用户再次点击已激活预设或点击重置
- **THEN** 系统恢复默认筛选状态

### Requirement: 开发者接口调用示例与技术规格

活动详情弹窗必须（MUST）为原生 API 资源展示技术参数（包含支持的模型、上下文窗口大小、Tool Calling 支持、协议兼容性）并提供可直接复制的 cURL 请求示例代码块。

#### Scenario: 查阅原生 API 详情并复制代码

- **WHEN** 用户点击原生 API 资源的“查看详情”
- **THEN** 弹窗内展示完整技术指标与 cURL 代码块，点击复制按钮可将请求模板复制至剪贴板

### Requirement: 临期高亮与视觉状态微动效

对于截止时间距离当前小于等于 3 天的活动，系统必须（MUST）在倒计时标签与卡片上展示显著的临期预警颜色（如琥珀橙）与视觉动效，提升用户决策时效。

#### Scenario: 临期活动高亮

- **WHEN** 活动有效且距离截止时间不超过 3 天
- **THEN** 时效标签高亮突出显示，标明剩余天数倒计时
